# pi-session-recap

A planned Pi extension for remembering a session’s task and recent activity after time away.

This repository is initialized only; no extension code is included yet.

The intended starting point is [tmustier’s session-recap](https://github.com/tmustier/pi-extensions/tree/main/session-recap). Upstream code, license, and attribution will be preserved when imported. Fix integration and Pi 1.0 / Herdr compatibility checks will follow.
